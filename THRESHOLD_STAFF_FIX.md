# Threshold ownership correction

- Removed Threshold Settings from the Admin Console.
- Step 3 is now an editable staff workflow step.
- Only the staff member allocated to the selected paper can read or save its threshold settings.
- Staff can configure marks threshold, target, CIA/ESE weights and CIA components.
- CIA + ESE weights must total 100.
- Settings become read-only after mark entry locks them.
- Existing records using the old configuredByAdmin flag remain compatible.
